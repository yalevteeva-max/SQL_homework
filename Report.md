# Отчет по домашнему заданию "Основы SQL"

## Запрос №1: Общая сумма завершенных заказов

*Описание запроса:*
С помощью данного запроса вычисляется суммарная стоимость всех завершенных заказов путем умножения количества на цену по каждой позиции и последующего суммирования. Считаются только заказы со статусом «completed»(выполненные). 

*Бизнес-интерпретация:*
Следует использовать для оценки фактической выручки компании. Позволяет анализировать объем продаж за определенный период без учета незавершенных или отмененных заказов, что важно для финансового планирования и оценки эффективности работы.

*Оптимизация:*
Индексы на `orders.status` и `order_items.order_id` ускорят выполнение подзапроса и соединения таблиц.

## Запрос №2: Клиенты с одним заказом и более

*Описание запроса:*
Группировка данных о заказах по ID клиента и подсчет количества заказов для каждого. Идет выборка клиента, оформившего более одного заказа.

*Бизнес-интерпретация:* 
Используется для выявления постоянных клиентов. Полученные данные могут применяться для предоставления скидок, удержания клиентов и разработки программ лояльности.

*Оптимизация:*
Индекс на `orders.customer_id` ускорит операцию группировки.

## Запрос №3: Товары с остатком меньше 5

*Описание запроса:* 
Выбираются товары, количество которых на складе составляет менее 5 единиц.

*Бизнес-интерпретация:* 
Помогает отделу закупок вовремя пополнять запасы продукции. Позволяет предотвратить дефицит товаров и избежать потери продаж.

*Оптимизация:* 
Индекс на `products.stock_quantity` ускорит фильтрацию по условию.

## Запрос №4: Самый популярный товар

*Описание запроса:*
Суммирует количество проданных единиц по каждому товару, сортировка результата по убыванию и вывод товара с максимальным показателем.

*Бизнес-интерпретация:* 
Используется для определения наиболее востребованного товара. Данные применяются при планировании закупок, для управления ассортиментом, проведения рекламных акций. 

*Оптимизация:*
Индекс на `order_items.product_id` ускорит операцию группировки.

## Запрос №6: Заказы с суммой больше 10 000

*Описание запроса:*

*Бизнес-интерпретация:*

## Запрос №7: Категории с наибольшей выручкой

*Описание запроса:*
Соединяет заказы с товарами. Группирует по категории и считает общую выручку. Сортировка по убыванию.

*Бизнес-интерпретация:* 
Применяется для определения наиболее прибыльных категорий товаров. Данные могут использоваться при планировании закупок и распределении бюджета.

*Оптимизация:*
Индексы на `order_items.product_id` и `products.category` ускорят соединение и группировку.
